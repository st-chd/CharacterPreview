# 캐릭터 미리보기 (ST-CharacterPreview)

캐릭터 카드를 클릭하면 대화를 열기 전에 이름, 이미지, 설명과 첫 메시지를 살펴볼 수 있는 SillyTavern 확장입니다. 원본 Character Details Popup을 바탕으로 한국어 UI와 설정 화면을 개선한 포크입니다.

## 변경 사항 (1.1.0)

- 설정, 버튼, 항목명, 오류 안내와 접근성 레이블 한국어화
- 설정을 카드 형태로 정리하고 슬라이더와 숫자 입력 동기화
- 테마 연동 상태, HEX 입력, 색상 조합 미리보기 추가
- 본문색 적용과 배경 전용 불투명도로 밝은 테마 가독성 개선
- 반응형 기준 너비가 실제 이미지·이름 배치에 적용되도록 수정


## 사용법

- 캐릭터 카드를 클릭하면 미리보기가 열립니다.
- **대화 시작**을 누르면 해당 캐릭터의 대화를 엽니다.
- **닫기**, Esc 또는 창 바깥 클릭으로 닫습니다.
- Shift를 누른 채 캐릭터 카드를 클릭하면 미리보기를 건너뜁니다.
- 첫 메시지가 여러 개면 화살표로 넘기거나 각각 접고 펼칠 수 있습니다.
- 캐릭터 카드의 내용은 자동 번역하지 않습니다.

## 설정

확장 메뉴의 **캐릭터 미리보기**에서 변경합니다. 설정은 자동 저장됩니다.

### 창 크기와 여백

모든 슬라이더에 숫자 입력을 함께 제공합니다. 입력 범위를 벗어난 숫자는 입력을 마칠 때 허용 범위로 보정하고, 빈 입력은 마지막 유효한 값으로 되돌립니다.

- 기본 너비: 넓은 화면에서 사용할 창 너비입니다.
- 최대 너비 / 높이: 화면 크기 대비 창의 최대 크기입니다. 작은 화면에서는 최대 너비를 기준으로 표시합니다.
- 안쪽 여백 / 모서리 둥글기: 창 내부 간격과 모서리를 조절합니다.

### 색상과 효과

글자, 창 배경, 대화 시작 버튼, 닫기·이동 버튼의 색상을 각각 설정할 수 있습니다.

1. 직접 지정할 항목의 **테마 색상 사용**을 끕니다.
2. 색상 선택기를 누르거나 HEX 코드(예: `#fff5f8`)를 입력합니다.
3. 바로 아래의 **이렇게 보여요**에서 조합을 확인합니다.

**창 배경 불투명도**는 배경에만 적용되며, 글자와 이미지는 흐려지지 않습니다. 테마 배경에 투명도가 포함되어 있어도 여기서 지정한 불투명도를 사용합니다. **바깥 배경 어둡기**는 창 뒤의 화면을 어둡게 하는 정도이며, **배경 흐림**은 뒤쪽 화면을 흐리게 합니다.

밝은 테마에서는 테마 본문색을 글자색으로 사용하고, 항목 배경과 구분선은 본문색을 옅게 섞어 표시합니다. 테마 연동을 끈 글자색·배경색의 조합은 직접 조정할 수 있습니다.

### 이미지와 배치

이미지 최대 높이와 이미지·이름을 나란히 배치할 기준 너비를 설정합니다. 기준은 화면 전체가 아니라 **미리보기 창의 너비**입니다.

### 내용과 표시 순서

설명, 첫 메시지, 시나리오, 성격, 제작자 노트, 대화 예시를 각각 설정합니다.

- 눈 아이콘: 표시 / 숨김
- 펼쳐 두기: 미리보기를 열었을 때 해당 항목을 펼친 상태로 표시
- 위 / 아래 화살표: 표시 순서 변경

**기본값으로 되돌리기**는 이 확장의 설정만 초기화합니다.
